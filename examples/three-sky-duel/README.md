# three-sky-duel

Created: 2026-10-15
Purpose: sample three.js (r170) game for KUMODeck Game Studio — two planes race through rings. Named groups
(`plane-you`, `cloud` ×6 → `cloud#2` …), repeated names (`ring` ×5) and a follow camera written in
`scene.onBeforeRender`, which the editor must not let move its own view.

- `index.html`, `game.js`, `studio-placement.js`, `style.css`
