# phaser-garden

Created: 2026-10-15
Purpose: small Phaser 4 scene for the Phaser adapter: SVG images, named and unnamed objects, a nested Container (fence with posts), a repeated name, a `studioKey` marker, a HUD and a background the studio leaves out, a drifting cloud.

- `index.html`, `game.js` — the game
- `placement.js` — loader that applies `placement.json` (what an AI agent adds)
- `assets/` — images
- `.studio/adapter.js` — copy of `src/adapters/phaser/adapter.js`
