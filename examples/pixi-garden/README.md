# pixi-garden

Created: 2026-10-15
Purpose: small PixiJS v8 scene for the Pixi adapter: Sprites from SVG files, labelled and unlabelled objects, a nested Container, a repeated label, a `studioKey` marker, a UI layer and background marked `studio = false`, a stage scaled to fit the window, a drifting cloud.

- `index.html`, `game.js` — the game
- `placement.js` — loader that applies `placement.json` to the stage
- `assets/` — images
- `.studio/adapter.js` — copy of `src/adapters/pixi/adapter.js`
