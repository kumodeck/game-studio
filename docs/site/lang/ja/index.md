# ゲームスタジオの使い方

ゲームスタジオは、Claude Code や Codex で作るウェブゲームのための、無料のエディタです。ゲームの中の物を手で動かし、同じ画面で AI に頼み、**保存** を押す。あとは AI がゲームのコードに入れます。

![見本「Lantern Cove」を開いたエディタ。左にシーンの一覧、真ん中にゲーム、下に AI に頼む欄](media/open.webp)

手元のパソコンで動き、アカウントは要りません。どこにも何も送りません。

## まずここから

- [はじめる](getting-started.md): 1 行で入れて、`/arrange` と打つ。
- [編集](editing.md): 選ぶ・動かす・回す・大きさを変える・見回す。**保存** で何が起きるか。
- [遊ぶ](play.md): エディタの中でゲームを遊び、止めて、見ていることを AI と話す。

## もっと使う

- [動き](motion.md): タイムラインで物を動かし、いつ動き出すかを決める。
- [レベル](levels.md): ゲームのレベルを切り替え、写して増やし、名前を変える。
- [UI の編集](ui.md): ゲームの上のタイトル・スコア・ボタンを動かす。
- [AI で作る](make-with-ai.md): 画像・3D モデル・音を作る（任意。KUMODeck のアカウントで）。

## しくみ

- [しくみ](how-it-works.md): エディタが書くファイルと、ゲームがそれを読むしかた。
- [よくある質問](faq.md): エディタのリンク・Node.js・Codex・困ったとき。
