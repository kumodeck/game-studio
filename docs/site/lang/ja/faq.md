# よくある質問・困ったとき

よく聞かれることと、うまくいかないときにすること。

## エディタのリンク

**リンクに合言葉があるのはなぜ？** エディタはゲームのフォルダを読み書きできるので、開けるのはあなただけにしています。そのための合言葉（`?t=` のあと）です。エディタを起動するたびに変わります。

**「Missing pass」と出る。** リンクの全部を使わずに開いています。エディタが開くと合言葉はアドレス欄から消えるので、タブのアドレスをコピーしても使えません。AI にリンクを聞いてください。

**「This link is not valid」と出る。** エディタが起動し直して、合言葉が変わりました。AI にリンクを聞いてください。

**リンクを人に渡せる？** 渡せません。このパソコンでしか開けません。

## ブラウザで開く

エディタはいつものブラウザでひとりでに開きます（Claude アプリでも）。チャットの横の枠がよければ、AI に「アプリの中で開いて」と言ってください。このゲームでは次からもそうします。「ブラウザで開いて」で元に戻ります。開かなかったときも、リンクは AI の返事の 1 行目にあります。

枠の中の **大きく開く**（↗）で、同じエディタを大きな窓で開けます。小さいほうは閉じてかまいません。

## Node.js

**「Game Studio needs Node.js 22.13 or later」と出る。** [nodejs.org](https://nodejs.org) から最新の LTS を入れて、もう一度 AI に頼んでください。この確かめより前には何も変えていません。

## Codex

Codex でも同じように使えます。ちがいは少しです。

| | Claude Code | Codex |
|---|---|---|
| エディタを開く | `/arrange` | `$arrange`、またはふつうの言葉で |
| 更新 | 自動で更新できる | `codex plugin marketplace upgrade game-studio` で更新 |
| エディタの AI の行 | 「詳しくは Claude で」 | 「詳しくは Codex で」 |

## three.js のゲームではない

three.js はそのまま使えます。Phaser・PixiJS・canvas・HTML のゲーム・Godot の Web 書き出しなら、AI に「このゲームの Game Studio のつなぎを書いて」と頼んでください。入っている例からつなぎ（アダプタ）を書き、エディタが動くかを確かめます。

## うまくいかないとき

**「このゲームはまだ Game Studio につながっていません。」** three.js のゲームは自動でつながります。ほかのエンジンでは、AI に「このゲームの Game Studio のつなぎを書いて」と頼んでください。

**「このゲームでは、まだ動かした位置が残らないことがあります。」のような行が出る。** エディタの確かめで何か見つかりました。詳しくは AI に伝えてあります。「Game Studio のつなぎを直して」と頼んで、読み込み直してください。

**「ゲームがエラーで止まりました」。** AI に直してもらってから、**読み込み直す** を押してください。エディタはそのまま使えます。

**変えたのにゲームに出ない。** **保存** を押しましたか？ 保存の前は下書きです。保存すると AI がゲームに入れます。何をしたかは AI の窓で見られます。

**レベルや UI の切り替えが出ない。** ゲームがエディタに教える必要があります。[レベル](levels.md#レベルが出ないとき) と [UI の編集](ui.md#ワールド--ui-が出ないとき) を見てください。

## 試し版

このサイトの試し版は、ブラウザの中で 2 つの見本のゲームを使ってエディタを動かします。AI にはつながっていないので、頼む欄はありません。変えたものは、このブラウザの中だけに残ります。
