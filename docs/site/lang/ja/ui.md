# UI の編集

多くのゲームには、世界の上に文字やボタンの層があります。タイトル、スコア、スタートボタン。これも動かしたり、大きさを変えたりできます。

これは UI の編集の第 1 段です。HTML で作った UI で使えます。[まだできないこと](#まだできないこと) も見てください。

## ワールド と UI

エディタで編集できる UI がゲームにあると、上のバーに **ワールド | UI** が出ます。**UI**（<kbd>U</kbd>）を押すと UI を編集します。世界は暗くなり、一覧は **画面の上の物** になります。

![UI の層。タイトルを選んで動かしたところ。後ろの世界は暗い](media/ui-layer.webp)

- UI をクリックして選び、ドラッグで動かします。
- 下の帯に **移動** と **大きさ** があります。<kbd>+</kbd> と <kbd>−</kbd>、カードの **大きさ** でも変えられます。真ん中の位置は変わりません。
- 戻す・進む は 2 つの層をまたいで使えます。

**ワールド**（<kbd>U</kbd>）で戻ります。世界を編集している間、ゲームの UI はじゃまにならないよう隠れています。切り替えの隣の目（<kbd>Shift</kbd><kbd>U</kbd>）で薄く見えます。クリックは世界に通ります。

スマホでは、切り替えはゲームの上の 2 つの絵です。

## ワールド | UI が出ないとき

エディタが扱えるのは、ゲームが印を付けた UI だけです。AI に頼んでください。「ゲームスタジオで UI を編集できるようにして」。タイトルやスコアなど、ゲームの HTML の 1 つずつに印を付けます。

## 保存

保存すると、それぞれをどこに動かしたか、どの大きさにしたかを書きます。ゲームは始まる時に、ほかの配置といっしょにそれを読みます。エディタがあってもなくても、タイトルは置いた所に出ます。

## まだできないこと

- HTML の UI だけです。ゲームの中で描く HUD（Phaser・PixiJS・three.js）は次の段で。
- 動かす・大きさだけ。回す・複製・削除はできません。
- ゲームが自分で位置を変える物（動くスコアなど）は一覧に出ません。
