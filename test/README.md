# test

Unit tests run with `node --experimental-strip-types --test test/<file>`.
Browser checks run headless.

- `first-run.test.mjs` — the first 5 minutes without a browser: starters read from the agreed shape (`starter.json`), only the game copied (no thumb / README / hand-off notes), never overwriting, the three-crates / pixi-garden fallback, the real CLI's `studio: no-game` (exit 4) / `--starters` / `--starter`, an old `intro` in prefs.json dropped, and the Node check (with a real old Node when one is installed, or `STUDIO_OLD_NODE=<node>`). Fake starters in `first-run/`
- `studio-first5.browser.mjs` — the same in a headless browser: an empty folder → `--starter 3d` → the editor → pick → drag → ask → Save, with no first-run tips at any step (removed 2026-10-17), and none on the phone either. `--real` (the plugin's own starters or the fallback), `--starters-dir <dir>`, `--shots <dir>`, `--video <file.mp4>` (Chrome screencast → ffmpeg), `--lang ja`
- `studio-e2e.browser.mjs` — the whole studio per example (select, the tool strip, dragging the picked object, undo, the draft written quietly, Save, Assets, a next step from ⌘K)
- `studio-transform.browser.mjs` — resizing several together / each in place (feet on the ground, one undo step) and the 3D turn axes (turn / tip forward / tip sideways around the box middle, R), saved `t` and reopened: three-crates PC and phone, pixi-garden PC. `--shots <dir>`
- `studio-tool-modes.browser.mjs` — the tool strip's tools: a tap on a button chooses it (it stays pressed; the first time, a line on how to look around), then a drag from anywhere (not on the object) does it — height, turn (15° steps), size, move — with a readout next to the strip, one undo step, the view unchanged; Option-drag / right-drag (mouse) and two fingers (touch) look around without touching the object; M / H / T / S in the game frame and in the editor page, Escape drops the tool first; several picked turn together; nothing picked = look around: three-crates PC and phone, pixi-garden PC. `--shots <dir>`, `--only pc|phone`
- `studio-tool-options.browser.mjs` — the ▾ on the strip's turn / size buttons: shown only where there are choices (3D turn with one picked, size with several; never 2D turn), inside the button's corner (the strip never moves by 1 px, phone buttons stay 44 px); one tap on a button only chooses the tool, one tap on the ▾ (or a long press on the button) opens the choices, PC hover lights the ▾; a choice chooses its tool and the button wears its picture; Escape in the game, Escape and a press in the editor page close them: Lantern Cove and Firefly Ruins, PC and phone, light and dark. `--shots <dir>`, `--only pc,phone`, `--theme light|dark|both`, `--game`
- `studio-thumbs.browser.mjs` — the list's pictures with hundreds of objects (pixi-garden + a crowd, 283): scrolled through top to end, every row in view gets its picture; one picked far down shows its row, and on a phone the sheet opened with it picked keeps the object above the sheet.
